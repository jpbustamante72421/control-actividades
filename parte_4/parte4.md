1. Explica la diferencia entre Git y GitHub.
Git es una herramienta que controla y registra los cambios que se realizaron en un proyecto y GitHub es 
una plataforma en donde se pueden almacenar repositorios y subir tus proyectos.

2. Explica para qué sirve .gitignore.
Sirve para indicar qué archivos o carpetas no deseas que aparezcann en el GitHub.

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.
Porque contiene demaisados archivos que ocupan espacio y cuando se suben a GitHub se ve demasiado mal

4. Explica para qué sirve requirements.txt.
Sirve para registrar las librerías instaladas en el entrono virtual y sus versiones necesarias para 
ejecutar un proyecto en otra computadora. 

5. Explica la diferencia entre Stage, Commit y Push.
El stage repara los cambios que se quieren guardar mediante git add, el commit guarda los cambios 
preparados en el historial del repositorio local y el push envía los commits locales a la nube

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.
Porque Git permite guardar diferentes cambios de manera local sin necesidad de conexión a internet y 
posteriormente con un git push se suben todos los archivos.
